Memory Game

A fun and interactive fruit game built with HTML, CSS, and JavaScript. The project features colorful fruit illustrations and a simple, user-friendly interface.

✨ Features
🍎 Colorful fruit illustrations created with SVG.
🎮 Interactive game elements.
🎨 Clean and attractive user interface.
📱 Responsive design for different screen sizes.
⚡ Smooth and lightweight performance.
🛠️ Technologies Used

HTML5 — Provides the structure of the game.
CSS3 — Creates the visual design and layout.
JavaScript (ES6+) — Adds interactivity and game functionality.
SVG — Creates scalable fruit illustrations.
